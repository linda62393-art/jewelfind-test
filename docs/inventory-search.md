# 管理員商品查詢

登入 `/admin` 後選「商品查詢（SKU／型號）」。不必建立或選擇需求單；可輸入完整 SKU、完整型號、部分型號。查詢忽略大小寫、空白及連字號，但顯示與儲存保留完整原始 SKU 及第一個 `-` 後的完整型號。

同型號不同 SKU 會列出各筆寄售店家、來源狀態與庫存；包含售出商品。沒有店家的商品明確標示「尚未登記店家」。每頁六筆。需求詳情另有「查這件商品的寄售店家／同款商品」。

來源為使用者商品總表的「寄售店家」欄。此資料不是即時定位，更新店家／售出需重新匯入總表。畫面顯示來源檔名及匯入時間。

`product_inventory` 僅允許已授權管理員 SELECT；查詢 RPC 使用 SECURITY INVOKER 並檢查管理員權限，未登入及一般帳號不可查詢。店家資料及總表不得提交公開 GitHub，私下透過受授權的 Supabase 管理連線匯入。此更新不改動客戶商品推薦或需求進度，也不自動聯絡客人／店家。

驗證：前端建置、lint、既有測試；`supabase/tests/inventory-search.sql` 驗證 SKU／型號查詢、連字號容錯、完整型號、分頁、缺值、售出及權限，所有測試資料回滾。

總表匯入準備：`python3 scripts/prepare-inventory-import.py workbook.xlsx /private/output.json`。腳本依欄位名稱讀取，保留完整型號、檢查重複 SKU，不讀入成本或內部備註。輸出須留在私有位置，透過授權 Supabase 管理連線做交易式 upsert。
